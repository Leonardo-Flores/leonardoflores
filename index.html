## about

I'm Leonardo Flores, a full-stack software engineer in São Paulo, Brazil — 10 years in technology. I started in infrastructure and moved into development, which shaped how I build: reliability, performance, and maintainability from the first commit.

Today I'm the sole engineer behind a retail company's entire technology platform: a point of sale processing live payments (PIX, cards, TEF terminals), executive dashboards with sub-100ms KPI reads, a factory-floor Rust/Tauri desktop app with RFID, and 100% keyless CI/CD on AWS — 4 products shipped to production in 6 months. I've also integrated AI/LLMs into production, including an AI/OCR pipeline that eliminated manual data entry on a factory floor.

typescript · react · node.js · python · rust · aws · terraform · postgresql

## selected work

open-pos

A point-of-sale system with pluggable payment providers. Adapter pattern for PIX/cards/cash, prices snapshotted at sale time, money in integer cents, and a deterministic decline path for demos. React 19, Hono, PostgreSQL.

 terraform-aws-oidc-starter

Keyless AWS deploys from GitHub Actions: OIDC trust pinned per repo and branch, read-only plans on PRs, gated applies on main. Zero static credentials — use it as a template.

 vilavest

E-commerce platform built with a Go backend, React storefront, and PostgreSQL — fully dockerized.

 dotfiles

The Arch + Hyprland environment this site recreates — Catppuccin Mocha everywhere, managed with GNU Stow.
